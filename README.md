# Веб-приложение для детской столярной мастерской «Ясна» (г. Сургут)

Полноценное Full-Stack веб-приложение для автоматизации расписания, онлайн-записи детей, журнала посещаемости, учёта абонементов и денежного баланса, онлайн-оплат через ЮKassa (СБП и банковские карты), прикрепления чеков из «Мой налог» и работы личного кабинета родителей без логина и пароля.

---

## Архитектура и технологический стек

- **Backend:** Node.js 22+, Express, TypeScript (`strict: true`), встроенный серверный SQLite (`node:sqlite`, файл `yasna.db`, `PRAGMA foreign_keys = ON`, `WAL`), `bcryptjs`, `multer`, `cookie-parser`.
- **Frontend:** React 19, TypeScript, Tailwind CSS v4, `motion/react`, монохромные иконки `lucide-react` (`strokeWidth={1.5}`).
- **Платёжная интеграция:** ЮKassa REST API v3 (`POST /v3/payments` с `Idempotence-Key` и поддержкой СБП/карт + независимая серверная верификация через `GET /v3/payments/{id}`).
- **Тесты:** `vitest` (`tests/booking.test.ts`, `tests/payment.test.ts`, `tests/security.test.ts`).

### Структура проекта
- `server.ts` — точка входа Express (API + Vite middleware в dev / статика `dist/` в production).
- `src/server/config.ts` — загрузка переменных окружения из `.env`.
- `src/server/db.ts` — инициализация SQLite, схема БД с `UNIQUE`/`CHECK` ограничениями и атомарные транзакции (`BEGIN IMMEDIATE`).
- `src/server/security.ts` — криптостойкие токены (`crypto.randomBytes(32)`), `bcryptjs`, подписанные `HttpOnly` cookie мастера, защита от IDOR.
- `src/server/services/` — бизнес-логика (`bookingService.ts`, `paymentService.ts`, `yookassaService.ts`, `notificationService.ts`, `exportService.ts`).
- `src/server/routes/` — маршруты (`publicRoutes.ts`, `parentRoutes.ts`, `masterRoutes.ts`, `webhookRoutes.ts`).
- `src/components/` — интерфейс расписания (`PublicSchedulePage.tsx`), личного кабинета родителя (`ParentCabinetPage.tsx`) и панели мастера (`MasterPanelPage.tsx`).

## Быстрый старт (локальный запуск)

1. **Установите зависимости:**
   ```bash
   npm install
   ```
2. **Создайте `.env` на основе `.env.example`:**
   ```bash
   cp .env.example .env
   ```
   Заполните параметры:
   - `MASTER_PASSWORD` — пароль входа в панель мастера (`/master`).
   - `SESSION_SECRET` — случайная строка для подписи сессионной cookie.
   - `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` — идентификатор магазина и секретный ключ из личного кабинета ЮKassa.
3. **Запустите сервер разработки:**
   ```bash
   npm run dev
   ```
   Приложение откроется на `http://localhost:3000`. При первом запуске БД `yasna.db` автоматически наполняется демонстрационными данными, а персональная ссылка семьи Смирновых выводится в консоль сервера.
4. **Запуск автотестов:**
   ```bash
   npm test
   ```

## Настройка ЮKassa и чеков «Мой налог»

1. В личном кабинете ЮKassa скопируйте `shopId` и `Секретный ключ` в `.env`.
2. В разделе **Интеграция → HTTP-уведомления** укажите URL вашего сервера:
   `https://<ваш-домен>/api/webhooks/yookassa`
3. Для тестирования без реального списания используйте тестовый магазин ЮKassa (`test_...`). При возврате с платёжной страницы ЮKassa кабинет родителя также автоматически выполняет синхронизацию статуса платежа через `GET /v3/payments/{id}`.
4. После оплаты мастер формирует чек в приложении «Мой налог» и во вкладке **«Оплаты и чеки»** прикрепляет ссылку на чек или загружает файл (`.pdf`, `.png`, `.jpg`, до 5 МБ). Родитель сразу видит кнопку «Открыть чек» или «Скачать чек» в своём кабинете.

## Резервное копирование и выгрузка CSV

- Во вкладке **«Правила и выгрузка»** в панели мастера доступны:
  - Скачивание CSV-отчётов (`Клиенты`, `Посещения`, `Оплаты`) в кодировке `UTF-8 BOM` с разделителем `;` для корректного открытия в Microsoft Excel.
  - Скачивание атомарного снимка базы данных `yasna.db` (`VACUUM INTO`).
  - Импорт семей и детей из CSV-выгрузки «МойКласс».

## Реализованные функции (v1) и границы прототипа

### Реализовано в v1:
- Публичное расписание `/schedule` с форматами, тарифами и точным количеством свободных мест.
- Личный кабинет родителя `/lk/{access_token}` без пароля (поддержка нескольких детей, перевыпуск ссылки с мгновенным отзывом старой, защита от подбора числовых ID).
- Раздельный учёт **остатка занятий по абонементам** и **денежного баланса / задолженности**.
- Атомарная запись на групповые и индивидуальные занятия с защитой от переполнения группы (`409 Conflict`) и повторной записи.
- Лист ожидания с автоматическим уведомлением при освобождении места и запись на отработку пропуска.
- Журнал посещаемости мастера (`Посетил`, `Пропустил`, `Отмена`), история исправлений (`attendance_logs`) и автоматический возврат/списание занятий.
- Настраиваемые в интерфейсе правила отмен и списаний (`free_cancel_hours`, `charge_on_miss`, `charge_on_late_cancel`).
- Онлайн-оплаты через ЮKassa (СБП и карты) со строгой идемпотентностью и ручной учёт оплат (наличные / перевод).
- Прикрепление ссылок и файлов чеков из «Мой налог» с защищённой выдачей файлов.
- Выгрузка CSV, импорт из «МойКласс» и скачивание резервной копии SQLite.

### Осознанные ограничения прототипа v1:
- Автоматическая фискализация чеков через API «Мой налог» не выполняется (чеки прикрепляются мастером вручную ссылкой или файлом по условиям ТЗ).
- Уведомления работают внутри личного кабинета родителя; внешние боты Telegram / VK подключаются на следующем этапе развития.
